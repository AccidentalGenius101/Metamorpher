# Security policy

Metamorpher 0.x is a research prototype and has no production-support promise.
Do not connect it directly to high-consequence execution systems.

For a vulnerability that would put users at immediate risk if disclosed
publicly, contact the repository owner through GitHub before publishing full
exploit details. For ordinary correctness, oracle leakage, stale-decision,
evidence, or backend-parity defects, open a reproducible issue.

Reports should include the affected version or commit, environment, minimal
reproduction, expected invariant, observed behavior, and whether an external
action could be executed incorrectly. Never include credentials or private data.
