# Name and trademark guidance

“Metamorpher” identifies the canonical project and its official releases. This
file is naming guidance, not an assertion that the name is a registered
trademark and not an additional restriction on the Apache-2.0 code license.

You may truthfully say that software uses, integrates, is compatible with, or is
derived from Metamorpher. Please do not use the name, logo, or confusingly
similar branding in a way that implies an unofficial fork, service, product, or
publication is endorsed by or is an official release of the canonical project.

Modified distributions should use a distinguishable name or a clear qualifier,
for example “ExampleCo Metamorpher fork,” and should state the upstream version
or commit when practical. Academic citation and ordinary descriptive use are
welcome; see `CITATION.cff`.
